# استعلام بطاقات الضمان الصحي – قسم الأنبار

واجهة Next.js للبحث في البيانات المنشورة رسميًا ضمن Google Sheet وعرض بيانات المستفيد وموعد ومكان المراجعة مع إمكانية الطباعة.

## الشيت المستخدم

- ID: `1NDqKDCvqPd9sr5dHMLlmVWujAid4M5KK`
- الصفحة: `جميع الدفعات`

## المزايا

- بحث عربي مرن بالاسم أو جزء منه.
- عرض جميع البيانات الرسمية المتاحة، بما فيها الرقم الوطني.
- دعم أسماء بديلة لعناوين أعمدة الشيت لتقليل الأعطال عند اختلاف الصياغة.
- عرض اللجنة ومكان المراجعة من الشيت إذا كانا موجودين.
- عند عدم وجود أعمدة اللجنة/المكان، يتم استنتاجهما من السكن وفق أماكن المراجعة المعلنة في محافظة الأنبار.
- عرض جميع النتائج المطابقة بدون حد 100 نتيجة.
- إزالة النتائج المكررة المتطابقة.
- زر لطباعة بطاقة المستفيد وتعليمات المستمسكات المطلوبة.
- تحويل البحث إلى POST حتى لا يظهر الاسم في عنوان URL.
- مهلة اتصال مع Google Sheet مع استخدام آخر نسخة ناجحة في ذاكرة السيرفر عند التعذر المؤقت.
- حماية بسيطة من الضغط المفرط على مسار البحث.
- عرض وقت آخر تحديث للبيانات التي قرأها السيرفر.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح:

`http://localhost:3000`

## البناء للإنتاج

```bash
npm run build
npm start
```

## النشر على Vercel

1. ارفع المشروع إلى GitHub.
2. من Vercel اختر Add New > Project.
3. اختر المستودع ثم Deploy.
4. لا يحتاج المشروع إلى API Key أو Service Account طالما أن Google Sheet متاح للعرض العام.

## ملاحظات تشغيلية

- يجب إبقاء اسم صفحة الشيت `جميع الدفعات` أو تعديله داخل `lib/sheet.ts` إذا تغير.
- الأفضل إضافة أعمدة `اللجنة` و`مكان المراجعة` داخل الشيت مستقبلاً، لأن البيانات الرسمية الموجودة في الشيت تُعتمد قبل الاستنتاج من عنوان السكن.
- إذا تغيرت أماكن اللجان، حدث القواعد الموجودة في `lib/committee.ts`.


## البحث العربي المرن (v2.1)
يدعم البحث اختلاف كتابة الأسماء المركبة والمسافات مثل `نور الدين/نورالدين` و`عبد الله/عبدالله`، كما يوحّد لأغراض البحث فقط أشكال `ة/ه` و`ى/ي` والهمزات وبعض الحروف العربية/الفارسية الشائعة، مع تجاهل التشكيل والتطويل وعلامات الترقيم. يبقى الاسم الأصلي في الشيت معروضًا بدون أي تعديل.

## Vercel deployment

- Project root must be this directory itself; `package.json` and `app/` are at the root.
- Framework Preset: Next.js.
- Root Directory: leave blank / `./`.
- Build Command: default (`npm run build`).
- Output Directory: leave blank (Next.js default).
- No environment variables are required for the current Google Sheet configuration.
